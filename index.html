Help & Documentation

Getting Started

  • Type your message in the input area and press Enter
  • Use Shift+Enter to create new lines in your message
  • Click suggested prompts to get started quickly
  • Previous conversations are saved in the sidebar

N8N Integration

  • Configure your N8N webhook URL in Settings
  • Create a workflow that responds to POST requests
  • Return responses in JSON format with a "message" field
  • See the README.md for detailed setup instructions

Keyboard Shortcuts

  • Enter - Send message
  • Shift + Enter - New line
  • Ctrl/Cmd + / - Show help
  • Ctrl/Cmd + , - Open settings
